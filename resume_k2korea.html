Section 02
직접 해결한 인프라 문제들
PROBLEM 01
방화벽 정책 변경 → 통신 두절, 재연결이 아닌 구조 재설계
통신 장애 접수 → Proxy 서버 IP 변경 이력 확인 → EC2 Elastic IP 고정 구조 재구성 → 재발 방지 구조 확보
로드밸런싱 환경에서 Proxy 서버 IP가 바뀌며 방화벽에 막혀 통신이 끊기는 장애가 발생했습니다. 임시 재연결이 아니라 IP가 다시 바뀌어도 재발하지 않는 구조로 근본적으로 정리하고, SSL 인증서 적용으로 전 구간 HTTPS 전환을 함께 완료했습니다.
PROBLEM 02
IT 자산 비용 부담 — IDC 환경 변경/클라우드 전환 실사
IDC 유지비용 부담 → 워크로드별 온프레미스/클라우드 구분 → 전환 가능 영역/유지 영역 실사 완료
IT 자산 비용 절감을 위해 IDC 환경을 변경하고 클라우드로 전환할 수 있는지를 직접 실사했습니다. 지연시간에 민감한 영역과 트래픽 변동이 큰 영역을 구분해 판단하는 과정을 실무로 경험했습니다.
PROBLEM 03
엑셀 산재 자산관리 — 시스템 자체 개발로 운영 리스크 제거
담당자 개인 엑셀 의존 → Java/Spring Boot/React 시스템 개발 → 실사용 데이터 2,394건 이관
담당자가 바뀔 때마다 자산 현황이 끊기는 문제를 발견하고, 데이터베이스 기반 자산관리 시스템을 직접 개발해 온보딩/라이선스 만료 관리까지 자동화했습니다.
PROBLEM 04
헬프데스크 처리 지연 — Power Automate/Webhook으로 알림 자동화
Form 접수 후 수동 확인/전달 → Power Automate + Teams Webhook → 담당자 자동 전달, 처리 이력 상세화
헬프데스크 문의를 사람이 옮겨 적던 과정을 자동화해 담당자에게 즉시 전달되도록 만들었고, 인수인계 시 정보 누락을 줄이기 위해 처리 이력도 상세화했습니다.
