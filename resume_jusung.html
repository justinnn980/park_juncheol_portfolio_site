Section 02
직접 해결한 인프라/보안 문제들
PROBLEM 01
방화벽 정책 변경 → 통신 두절, 재연결이 아닌 구조 재설계
통신 장애 접수 → Proxy 서버 IP 변경 이력 확인 → EC2 Elastic IP 고정 구조 재구성 → 재발 방지 구조 확보
로드밸런싱 환경에서 Proxy 서버 IP가 바뀌며 방화벽에 막혀 통신이 끊기는 장애가 발생했습니다. 임시 재연결이 아니라 IP가 다시 바뀌어도 재발하지 않는 구조로 근본적으로 정리하고, SSL 인증서 적용으로 전 구간 HTTPS 전환을 함께 완료했습니다.
PROBLEM 02
간헐적 CORS 오류/데이터 이관 누락 — 로그 단위 원인 추적
특정 조건에서만 재현 → 요청/응답 헤더, 이관 로그 비교 → 특정 API 경로/조건 원인 특정 후 해결
새로고침하면 다시 되는 오류라 그냥 넘길 수도 있었지만, 원인을 두면 사용자가 늘었을 때 더 자주 터질 거라 판단해 화면별로 헤더와 로그를 하나씩 비교해 원인을 좁혀 해결했습니다.
PROBLEM 03
엑셀 산재 자산관리 — 시스템 자체 개발로 운영 리스크 제거
담당자 개인 엑셀 의존 → Java/Spring Boot/React 시스템 개발 → 실사용 데이터 2,394건 이관
담당자가 바뀔 때마다 자산 현황이 끊기는 문제를 발견하고, 데이터베이스 기반 자산관리 시스템을 직접 개발해 온보딩/라이선스 만료 관리까지 자동화했습니다.
PROBLEM 04
헬프데스크 처리 지연 — 자동화하되 담당자 부재까지 대비
Form 접수 후 수동 확인/전달 → Power Automate + Teams Webhook + FAQ 챗봇 이중화 → 담당자 공백에도 안내 유지
헬프데스크 문의를 사람이 옮겨 적던 과정을 자동화했고, 담당자 한 명에게 문제가 생겨도 안내가 끊기지 않도록 관리자 계정 이중화 구조까지 함께 설계했습니다.
