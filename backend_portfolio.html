01 / (주)홈초이스 — 오초이스 OTT 앱 인프라

IP가 바뀌어도 끊기지 않는 통신 구조

앱과 서버 사이 중계 서버의 IP가 바뀌자 보안 정책에 막혀 요청이 전부 끊기는 장애가 있었습니다. LG헬로비전 / 딜라이브 두 대형 파트너사 앱을 오초이스로 전환하는 과정에서 통신 안정성이 핵심 과제였습니다.

  • Challenge

    중계 서버 IP 변경 시 방화벽 정책으로 앱-서버 통신이 전면 차단

  • Approach

    중계 서버에 고정 IP(EIP)를 할당해 IP 변동 요인을 제거하고, HTTP → HTTPS 전환 시 SSL 인증서를 적용해 전 구간을 암호화 통신으로 재구성

  • Result

    NCG/Multi로 서로 다른 두 DRM 체계를 단일 재생 구조로 통합, 콘텐츠 화면은 앱 배포 없이 반영되도록 웹 분리 구조까지 함께 구축

02 / 개인 프로젝트

Study Tracker API — 인증부터 CI/CD까지 혼자 완성

학습 Todo를 관리하는 REST API를 기획부터 배포까지 혼자 구현했습니다. 기능을 만드는 데서 끝내지 않고, 실무에서 겪을 법한 인증 / 성능 / 동시성 문제를 직접 설계해 해결했습니다.

  • Challenge

    Todo 번호만 알면 남의 데이터에 접근 가능, 통계 조회마다 DB 재계산, 중복 클릭으로 데이터 중복 생성

  • Approach

    jjwt 없이 HMAC-SHA256으로 JWT 서명을 직접 구현하고 타이밍 어택을 방어, Redis에 통계를 60초 캐싱하며 변경 시 즉시 무효화, 요청마다 멱등성 키를 부여해 재요청을 409로 차단

  • Result

    단위/통합 테스트 60건, GitHub Actions → Docker → Render로 이어지는 CI/CD 파이프라인, 상태 확인 API와 운영 문서까지 구축
