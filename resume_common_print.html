  • 광고 및 이용 통계 기능 연동, 성능 지표 확인 및 개선
주요성과
  • 기기 여러 대 연결 시 발생하던 화면 오류를 상태를 나눠서 관리하는 구조로 바꿔 해결, 상태 변화가 바로 반영되도록 개선
  • 화면 실시간 연동 구조를 설계해 로딩 속도 39% 개선, 앱 업데이트 없이 콘텐츠를 바로 반영할 수 있는 운영 구조 확보
  • 앱 개발 도구의 대규모 업그레이드 시 연결된 기능을 모두 재점검해 문제없이 전환 완료
  • 통신 오류로 서비스가 끊기던 문제를 근본적으로 해결해 안정적인 연결 구조 확보
