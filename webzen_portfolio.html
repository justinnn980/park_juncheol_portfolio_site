01 / (주)홈초이스 — 서버/네트워크 장애 대응

재연결로 넘어가던 통신 장애를 구조를 바꿔 끝냄

OTT 서버와 외부 시스템 사이의 통신이 갑자기 끊기는 일이 반복됐습니다. 다시 연결하면 바로 복구됐지만 원인을 모른 채 넘기면 사용자가 몰리는 시간에 또 생길 문제라고 봤습니다.

  • Challenge

    복구는 되지만 원인이 확인되지 않아 같은 장애가 되풀이되는 상태

  • Approach

    방화벽 기록을 시간순으로 추적해 중계 서버 IP 변경이 원인임을 확인. 바뀐 주소를 매번 다시 등록하는 대신 EC2 Elastic IP로 주소를 고정하고 SSL을 적용하는 구조로 재구성

  • Result

    IP가 바뀔 일이 없어져 방화벽 정책과 어긋나는 상황 자체가 사라짐

방화벽 정책 AWS EC2 / Elastic IP SSL 원인 추적

02 / 아우토크립트 — 임직원 계정 운영 자동화

사람마다 달랐던 입/퇴사 계정 처리를 하나의 절차로 고정

입사자 계정 생성과 퇴사자 계정 회수가 담당자의 기억과 손에 기대어 처리되고 있었습니다. 절차 자체를 시스템에 넣어 누가 처리해도 같은 순서와 같은 결과가 나오게 바꿨습니다.

  • Challenge

    처리 순서가 정해져 있지 않아 장비 지급이나 계정 회수가 빠질 수 있는 구조

  • Approach

    온보딩을 4단계 마법사 UI(정보입력 → 기기지급 → 계정생성 → 완료)로 표준화, 사번 자동 채번, 입/퇴사자 MS 365 계정 생성/회수 자동화

  • Result

    기기 지급과 계정 생성이 한 흐름에서 처리되고, 퇴사자 계정이 남지 않도록 회수까지 절차에 포함

03 / 아우토크립트 — 사내 기술지원(헬프데스크) 개선

접수된 요청이 담당자에게 바로 가고, 처리 과정이 기록으로 남게 함

헬프데스크 문의를 사람이 확인해 담당자에게 넘기다 보니, 자리를 비우거나 문의가 몰리면 전달이 늦어졌습니다. 접수부터 전달까지를 자동으로 잇고, 처리 내용은 다음 담당자가 읽고 이어받을 수 있는 수준으로 남겼습니다.

  • Challenge

    접수와 전달 사이에 사람이 끼어 있어 지연과 누락이 생기는 구조

  • Approach

    MS Form 접수를 Power Automate 흐름으로 받아 Teams Webhook으로 담당자에게 자동 전달, 처리 이력 항목을 상세화

  • Result

    접수 즉시 담당자에게 전달되고, 담당자가 바뀌어도 어디까지 처리됐는지 이력으로 확인

04 / 아우토크립트 — IT 자산 관리 체계 구축

아무도 요청하지 않은 엑셀 문제를 직접 시스템으로 만듦

조직도와 IT 자산 현황이 담당자마다 다른 엑셀 파일에 나뉘어 있어, 어떤 장비가 누구에게 가 있는지 파일끼리 맞지 않았습니다. 파일이 복사되며 버전이 갈라지는 게 원인이라 정리만으로는 다시 틀어질 구조라고 판단해, 모두가 같은 원본을 보는 웹 시스템을 직접 만들었습니다.

    담당자가 바뀌거나 파일을 잘못 덮어쓰면 자산 현황이 깨지는 파일 단위 관리

  • Approach

    Java/Spring Boot REST API와 React 화면으로 조직도 연동 자산관리 시스템 개발, Docker/Render API로 배포 자동화

  • Result

    실사용 데이터 2,394건 이관, 배포 후 발생한 CORS 오류와 이관 누락을 요청/응답 로그로 추적해 해결
