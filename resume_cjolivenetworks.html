PROBLEM 01

PROBLEM 02
NCG DRM → Multi DRM 전환 — 단일 플레이어로 통합
파트너사마다 다른 DRM 방식 → DRM 추상화 인터페이스 설계 → 서비스 무관 동일 시청 경험
딜라이브(NCG DRM)와 헬로tv(Multi DRM) 사이의 DRM 방식 차이를, DRM 타입을 내부에서 분기 처리하는 단일 플레이어 인터페이스로 추상화해 통합했습니다.
PROBLEM 03
헬프데스크 처리 지연 — 자동화하되 담당자 부재까지 대비
Form 접수 후 수동 확인/전달 → Teams 알림 연동 + FAQ 챗봇 이중화 → 담당자 공백에도 안내 유지
헬프데스크 Form 접수를 Teams 알림과 연동해 처리 속도를 개선했고, 담당자 한 명에게 문제가 생겨도 안내가 끊기지 않도록 관리자 계정 이중화 구조까지 함께 설계했습니다.
PROBLEM 04
간헐적 CORS 오류/데이터 이관 누락 — 로그 단위 원인 추적
특정 조건에서만 재현 → 요청/응답 헤더, 이관 로그 비교 → 특정 API 경로/조건 원인 특정 후 해결
새로고침하면 다시 되는 오류라 그냥 넘길 수도 있었지만, 원인을 두면 사용자가 늘었을 때 더 자주 터질 거라 판단해 화면별로 헤더와 로그를 하나씩 비교해 원인을 좁혀 해결했습니다.
