경력사항
(주)홈초이스 2024.02 ~ 2025.11 (1년 10개월) / 서버/네트워크 인프라 운영 및 서비스 개발

전국 디지털케이블TV 가입가구에 VOD를 공급하는 국내 유일 사업자인 (주)홈초이스에서 서버/네트워크 인프라 운영과 서비스 개발을 함께 담당했습니다. AWS EC2/S3/Elastic Beanstalk 기반으로 인프라를 운영하는 과정에서 로드밸런싱 환경의 Proxy 서버 IP가 변경되며 방화벽 정책에 막혀 통신이 끊기는 장애가 발생한 적이 있습니다. 임시 우회 조치로 서비스 영향을 즉시 차단한 뒤 EC2 Elastic IP를 고정 할당하는 구조로 재구성해 장애의 근본 원인을 해결하고 재발을 방지했습니다. 이어서 암호화되지 않은 통신 구간에 SSL 인증서를 적용해 전체 통신을 HTTPS로 전환하며 정보보안 측면의 개선도 함께 수행했습니다.

서비스 운영 과정에서는 가입자 343만 명 규모의 LG헬로비전과 매출 3,500억 원 규모의 딜라이브 등 복수 파트너사의 앱을 하나의 서비스로 통합 마이그레이션하는 작업을 진행했습니다. 두 회사의 DRM 방식과 셋톱박스 페어링 상태 관리 방식이 서로 달라 발생한 이슈를 각 파트너사 요구사항에 맞춰 조율하며 정책을 변경하고 장애를 처리했습니다. 서로 다른 시스템 환경을 가진 여러 조직과 동시에 소통하며 문제를 정리해본 이 경험은 여러 지사/부서가 서로 다른 IT 환경을 쓰는 상황을 조율해야 하는 정보관리 업무와 맞닿아 있다고 생각합니다.

반복되는 콘텐츠 메타데이터 수집 업무는 Python 기반 Selenium 스크립트와 Docker, Cron Job을 조합해 자동화했고, 장애 대응 절차와 인프라 변경 내역을 문서로 정리해 팀 내에서 공유하는 습관을 갖췄습니다. 데이터 처리에는 MySQL과 DynamoDB를 함께 사용했으며, 화면 로딩 구간별 소요 시간을 직접 측정해 병목 지점을 찾아 개선함으로써 첫 화면 표시 속도를 39퍼센트 단축시킨 경험도 있습니다. 사용자로부터 접수된 이상 현상은 증상 하나로 끝내지 않고 재생 시작부터 종료까지 단계를 나눠 원인이 되는 조건을 끝까지 좁혀가며 해결해왔으며, 이 과정에서 시스템 장애 대응과 사용자 지원 업무에 필요한 진단 역량을 실무로 익혔습니다.

직무 관련 역량

AWS EC2/S3/Elastic Beanstalk을 기반으로 한 클라우드 인프라 운영 경험과, 방화벽 정책 변경으로 발생한 장애를 구조적으로 재설계해 해결한 경험을 보유하고 있어 니프코코리아 정보관리 직무의 네트워크/클라우드 인프라 구축 및 운영 업무에 바로 적용할 수 있습니다. SSL/HTTPS 전환을 비롯한 통신 보안 개선 작업을 직접 설계하고 적용해본 경험은 정보보안/IT 거버넌스 운영 업무와도 연결됩니다.

Python을 활용한 자동화 스크립트 작성과 MySQL/DynamoDB 데이터 처리 경험을 갖추고 있으며, IT 인프라 전반에 대한 이해를 넓히기 위해 정보통신산업진흥원 인공지능 기본과정과 네이버 부스트코스 데이터사이언스 코칭스터디를 수료하며 꾸준히 학습해왔습니다. 새로운 기술 영역도 필요한 시점에 스스로 학습해 실무에 빠르게 적용해온 방식으로, 사내 표준 개발/보안 환경도 빠르게 익혀 업무에 적용하겠습니다.

지원동기
