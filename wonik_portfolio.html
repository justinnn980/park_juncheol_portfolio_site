02ROS Driving Project

ROS 기반 자율주행 RC카 주행 SW

2023.07 / 개인 실습 / DSC 공유대학 연계 자율주행 기술캠프(충남대) / 자이트론 자이카, Ubuntu 20.04 + ROS Noetic

STEP 1 / 센서 입력
토픽 구독
/usb_cam/image_raw와 xycar_ultrasonic을 콜백으로 수신하고, 첫 메시지가 도착한 뒤 주행을 시작합니다.
STEP 2 / 인지
차선/정지선/장애물
ROI를 잘라 차선 선분과 정지선을 검출하고, 초음파 거리값으로 벽과 전방 장애물을 판단합니다.
STEP 3 / 판단
주행 모드 전환
센서 주행 → 정지선 정차 → 차선 주행 → 종료 순서로 상태를 바꿉니다.
STEP 4 / 제어
모터 토픽 발행
조향각과 속도를 xycar_motor 토픽으로 발행해 구동부를 움직입니다.
장애물 회피
초음파 센서
좌/우 거리 비교로 조향, 전방 근접 시 정지
  • 왼쪽이 더 멀면 좌회전, 오른쪽이 더 멀면 우회전, 같으면 직진하도록 조향각을 결정했습니다.
  • 전방 거리가 기준 아래로 떨어지면 조향각은 유지한 채 속도만 0으로 내려 충돌을 막았습니다.
Obstacle Avoidance Int32MultiArray
차선 추종
USB 카메라
선분 검출 → 대표 직선 → 조향각
  • Gaussian Blur와 Canny Edge로 외곽선을 만들고 HoughLinesP로 선분을 검출했습니다.
  • 수평에 가까운 선분은 버리고, 기울기 부호와 화면 좌/우 위치로 왼쪽/오른쪽 차선을 분류했습니다.
  • 선분들의 평균 기울기와 중심점으로 대표 직선을 구하고, 두 차선 중점과 화면 중심의 차이를 조향각으로 썼습니다.
  • 한쪽 차선을 놓치면 반대쪽 차선 위치에서 차선 폭만큼 떨어진 값으로 보정해 주행을 이어갔습니다.
Canny / Hough 조향각 계산 cv_bridge
정지선 인식
USB 카메라
HSV 이진화와 흰색 픽셀 수로 판단
  • 영상 하단 ROI를 HSV로 바꿔 밝기(V) 채널 기준으로 이진화했습니다.
  • 검사 영역 안의 흰색 픽셀 수가 기준을 넘으면 정지선으로 판단해 1초 정차 후 주행 모드를 전환했습니다.

05Focus

일하는 방식

자율주행 RC카 실습에서 센서 값이 판단을 거쳐 실제 움직임이 되는 과정을 처음부터 끝까지 다뤘습니다. 카메라와 초음파 입력, 주행 모드 전환, 모터 명령이 토픽으로 이어지는 구조를 직접 돌려 보며, 주행 품질은 ROI 위치와 임계값, 조향 비율 같은 수치를 실제 환경에 맞추는 데서 결정된다는 것을 확인했습니다.
실무에서도 같은 방식으로 일했습니다. 통신 장애가 났을 때 재연결로 넘기지 않고 IP 변경 이력까지 추적해 구조를 바꿨고, 낙상 감지에서는 오탐 원인을 조건 단위로 나눠 임계값을 다시 잡았습니다. 모바일 로봇의 주행 기능도 센서 로그와 수치로 원인을 좁혀가며 튜닝하겠습니다.
