Section 02
직접 해결한 인프라/운용 문제들
PROBLEM 01
방화벽 정책 변경 → 통신 두절, 임시조치가 아닌 구조 재설계
통신 장애 접수 → Proxy 서버 IP 변경 이력 확인 → EC2 Elastic IP 고정 구조 재구성 → 재발 방지 구조 확보
로드밸런싱 환경에서 Proxy 서버 IP가 바뀌며 방화벽에 막혀 통신이 끊기는 장애를 재연결이 아닌 재발하지 않는 구조로 근본적으로 정리하고, SSL 인증서 적용으로 전 구간 HTTPS 전환을 완료했습니다.
PROBLEM 02
FAQ 챗봇 장애 리스크 — AI 결과물을 검증해 이중화 구조로 재설계
AI로 챗봇 초안 생성 → 관리자 공백/장애 리스크 직접 판단 → MS Form 우선 노출 이중화 구조
AI가 만든 단순 매칭형 챗봇 초안을 그대로 쓰지 않고, 관리자 퇴사/서버 장애 상황을 직접 고려해 오류가 적은 채널이 우선 노출되는 이중화 구조로 다시 설계했습니다.
PROBLEM 03
엑셀 산재 자산관리 — 데이터화해 클라우드 전환 판단 근거 확보
현황 데이터 부재 → Java/Spring Boot/React 시스템 개발 → 실사용 데이터 2,394건 이관
IDC/클라우드 전환을 판단하려면 현황 데이터가 먼저 필요하다는 걸 파악하고, 엑셀 산재 자산관리를 데이터베이스 기반 시스템으로 직접 전환해 판단 근거를 확보했습니다.
