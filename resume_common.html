Section 02
직접 해결한 문제들
PROBLEM 01
방화벽 정책 변경 → 통신 두절, 재연결이 아닌 구조 재설계
통신 장애 접수 → Proxy 서버 IP 변경 이력 확인 → EC2 Elastic IP 고정 구조 재구성 → 재발 방지 구조 확보
로드밸런싱 환경에서 Proxy 서버 IP가 바뀌며 방화벽에 막혀 통신이 끊기는 장애가 발생했습니다. IP가 다시 바뀌어도 재발하지 않는 구조로 정리하고, SSL 인증서 적용으로 전 구간 HTTPS 전환을 함께 완료했습니다.
PROBLEM 02
웹 전환 후 성능 저하 — 구간별 병목 분석으로 개선
FCP/LCP 저하 발생 → 스켈레톤 UI/Lazy Loading/이미지 리사이징 → FCP 39% / LCP 10.8% 개선
콘텐츠 포스터가 많은 화면을 앱에서 웹으로 분리하며 발생한 로딩 저하를 구간별로 분석해, 초기 렌더링 최적화로 체감 속도를 개선했습니다.
PROBLEM 03
DRM 방식이 다른 두 파트너사 앱 — 하나의 서비스로 통합
LG헬로비전(343만 명)/딜라이브(3,500억) → DRM/셋톱박스 페어링 동시 대응 → 단일 앱으로 통합 마이그레이션
DRM 방식이 서로 다른 두 파트너사 앱을 별도 솔루션 도입 없이 플레이어 커스터마이징으로 동일 UI를 제공하며 하나의 서비스로 통합했습니다.
PROBLEM 04
엑셀 산재 자산관리 — 시스템 자체 개발로 운영 리스크 제거
담당자 개인 엑셀 의존 → Java/Spring Boot/React 시스템 개발 → 실사용 데이터 2,394건 이관
담당자가 바뀔 때마다 자산 현황이 끊기는 문제를 발견하고, 데이터베이스 기반 자산관리 시스템을 직접 개발했습니다. 헬프데스크 Form 접수도 Power Automate/Teams Webhook으로 자동 연동했습니다.
