01 / 아우토크립트 — 사내 웹 애플리케이션 개발 및 운영

엑셀 정리 요청을 받고, 원본이 하나인 웹 시스템을 만듦

조직도와 IT 자산 현황이 담당자 개인의 엑셀 파일 여러 개에 나뉘어 있었습니다. 파일이 복사되며 버전이 갈라지는 게 원인이라 양식을 다듬어도 반복될 구조라고 판단해, 모두가 같은 원본을 보는 웹 시스템을 요구사항 정의부터 배포까지 직접 만들었습니다.

  • Challenge

    담당자가 바뀌거나 파일을 잘못 덮어쓰면 자산 현황이 깨지는 파일 단위 관리 구조

  • Approach

    Java/Spring Boot REST API와 React 화면으로 조직도 연동 자산관리 시스템 개발, 온보딩 절차를 4단계 마법사 UI(정보입력 → 기기지급 → 계정생성 → 완료)로 표준화, 사번 자동 채번과 SW 라이선스 만료 자동 경고 추가

  • Result

    실사용 데이터 2,394건 전량 이관, Docker/Render API로 배포 자동화, 배포 후 발생한 CORS 오류와 이관 누락을 요청/응답 로그로 추적해 해결

02 / 개인 프로젝트 — AI 코딩 도구를 활용한 API 서버 개발

AI가 쓴 코드를 읽고 믿는 대신, 테스트로 채택 여부를 정함

학습 Todo 관리 REST API(Study Tracker)를 Claude Code와 함께 설계부터 배포까지 만들었습니다. 반복 코드는 AI에게 맡기고, 인증/캐시/중복 요청처럼 틀리면 안 되는 부분의 기준은 제가 정했습니다.

  • Challenge

    AI가 생성한 코드는 읽는 것만으로 맞는지 판단하기 어렵고, 정상 요청만 보면 문제가 드러나지 않음

  • Approach

    실패하면 안 되는 상황을 테스트로 먼저 작성하고 통과한 코드만 채택, Redis 기반 중복 요청 방지와 캐시 무효화 규칙은 직접 설계

  • Result

    단위/통합 테스트 60건, JWT 인증, GitHub Actions, Docker 구성으로 배포하고 Swagger 문서 공개

Claude Code Java 21 / Spring Boot PostgreSQL / Redis
