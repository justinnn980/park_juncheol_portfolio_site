04Motivation & Vision

지원동기 및 비전

BGF에코머티리얼즈의 Technology Consulting 직무는 프로세스 진단부터 ERP / 데이터 시스템 구축까지 기업의 디지털 전환을 폭넓게 다룬다는 점에서, 제가 (주)홈초이스에서 직접 경험한 "운영 문제를 진단하고, 시스템을 재설계하고, 안정적으로 연동시키는 일"의 연장선에 있다고 생각합니다. 서로 다른 두 서비스를 하나의 아키텍처로 통합하며 비즈니스 요구와 기술 구조를 정렬해본 경험이, 이번 공고의 Master Planning / Process Innovation 영역과 맞닿아 있습니다.
ERP(SAP) 영역에서는 자격증이나 이론 공부에 머물지 않고 Mock SAP 서버 분리 / 전송 상태 관리 / 재처리 API까지 갖춘 OData 연동 구조와 MM/SD/FI/SAPUI5 패턴을 직접 구현하며 실무 투입 준비도를 갖췄습니다. Data Analytics 영역에서는 공공데이터 기반 수요예측과 Computer Vision 프로젝트로 데이터 분석 기초를 다졌고, Claude Code 같은 AI 도구를 기획부터 배포까지 실무로 활용해온 경험을 LLM 기반 생산성 / 원가 혁신 컨설팅에도 적용하고 싶습니다.
S&OP / 물류(TM/WMS) / 전사 MDM처럼 직접 참여해보지 못한 영역도 있습니다. 다만 외부 시스템 연동에서 다룬 상태 관리 / 재처리 구조 설계 원리는 도메인이 달라도 동일하게 적용된다고 판단하며, 빠르게 학습해 실무에 기여하고 싶습니다. 장기적으로는 프로세스 진단부터 ERP / 데이터 시스템 구축까지 아우르는 Technology Consultant로 성장하는 것이 비전입니다.
