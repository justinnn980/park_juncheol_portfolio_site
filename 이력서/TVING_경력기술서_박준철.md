아우토크립트(그린맨파워 파견)에서 IT 인프라/자산관리 담당으로 재직 중이며, 이전에는 (주)홈초이스에서 1년 10개월간 AWS 기반 서버/네트워크 인프라 운영과 Flutter 기반 OTT 앱 개발을 담당했습니다. 두 조직을 거치며 사내 IT 인프라 구축/운영, IT 자산 및 계정 권한 관리, 헬프데스크 체계화, 반복 업무 자동화까지 IT Support Engineer 직무에 필요한 실무를 두루 경험했습니다.

## 아우토크립트 — IT 인프라 및 자산관리 담당

자동차 소프트웨어 보안 분야 코스닥 상장기업의 사내 IT 인프라와 자산 전반을 담당하고 있습니다.

- **자산관리대장/조직도 기반 물품지급 사내사이트 구축** : 자산관리대장과 조직도가 분리되어 있어 임직원에게 필요한 IT 물품이 누락되거나 중복 지급되는 문제가 있었습니다. 자산관리대장과 조직도를 연동한 사내사이트를 구축해, 입사/조직 변경이 발생하면 담당 자산 현황이 자동으로 매칭되어 물품 지급이 누락 없이 진행되도록 개선했습니다.
- **헬프데스크 Form 접수 → Teams 알림 자동화** : IT 이슈가 메일/구두로 접수되어 처리가 누락/지연되던 문제를, MS Form 접수 표준화 + 접수 즉시 담당 엔지니어에게 Teams 알림이 전달되는 구조로 개선해 대응 속도를 높였습니다.
- **채팅방/FAQ 사이트 개발 (이중화 설계)** : 반복 단순 문의 우선 대응을 위해 채팅방과 FAQ 사이트를 개발하되, 관리자 퇴사/서버 다운 시 서비스가 중단될 리스크를 미리 예상해 MS 관리자 계정 기반으로 구성하고 채팅방/FAQ 사이트보다 MS Form을 우선 노출하는 구조로 설계해 특정 담당자/시스템에 종속되지 않도록 예방했습니다.
- **인수인계 프로세스 개선** : 처리 결과 위주였던 인수인계 자료에 증상/원인/조치를 상세히 남기도록 개선해, 동일 장애 재발 시 신속하게 대처할 수 있는 환경을 만들었습니다.
- **SW 라이선스 관리 사내사이트 구축** : 팀별로 개별 관리되던 SW 라이선스 현황을 한 곳에서 확인할 수 있도록 구축해 중복 구매/만료 누락을 방지하고 비용을 체계적으로 관리했습니다.
- **입/퇴사 시 MS 관리 시스템 자동화** : 수작업으로 처리하던 MS 계정 생성/회수, 그룹 권한 부여/회수를 자동화해 처리 누락과 소요 시간을 줄였습니다.
- **IT 자산 비용 절감을 위한 IDC 환경 변경 및 클라우드 전환 실사화** : IDC 운영 비용 구조를 분석해 클라우드 전환 시 비용 효율을 검토, 인프라 투자 계획 수립에 필요한 데이터를 정리했습니다.

## (주)홈초이스 — 서버/네트워크 인프라 운영 및 OTT 앱 개발
**기간** : 2024.02 ~ 2025.11 (1년 10개월)

전국 디지털케이블TV 가입가구에 VOD를 공급하는 국내 유일 사업자에서, AWS EC2/S3/Elastic Beanstalk 기반 인프라 운영과 Flutter 기반 OTT 앱 '오초이스'의 개발/운영을 함께 담당했습니다.

- **통신 장애 근본 해결** : 로드밸런싱 환경에서 Proxy 서버 IP 변경으로 방화벽 정책에 막혀 앱-서버 통신이 두절되는 장애를, 우회가 아닌 EC2 Elastic IP 할당 구조로 재구성해 근본 해결.
- **통신 구간 보안 전환** : 미암호화 중계 서버 구간에 SSL 인증서를 적용해 전 구간 HTTPS로 전환.
- **복수 사업자 앱 전환 프로젝트 2건 주도** : 매출 3,500억 규모 딜라이브(모바일TV), 가입자 343만 명 규모 LG헬로비전(헬로tv)을 오초이스 앱으로 전환. 딜라이브는 서로 다른 두 영상 보호 방식(NCG/Multi DRM)을 단일 재생 구조로 통합, LG헬로비전은 변경 잦은 화면을 웹 기반으로 분리해 앱 재배포 없이 즉시 반영되는 구조로 전환. 초기 로딩 지연은 리소스 경량화/이미지 CDN/스켈레톤 UI로 해결해 FCP 39%, LCP 10.8% 개선.
- **반복 업무 자동화** : 콘텐츠 메타데이터 수집을 Python/Selenium/Docker/Cron Job으로 자동화, 장애 대응 절차와 인프라 변경 내역을 문서화해 팀 내 공유.
- **Flutter 2→3 업그레이드** : 라이브러리 호환성 문제를 항목별 전수 점검해 서비스 중단/기능 손실 없이 완료.
