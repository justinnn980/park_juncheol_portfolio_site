Section 02
이상 현상을 어떻게 진단하고 해결했나
ISSUE 01
영상 재생 시 소리 중복 — 증상에서 멈추지 않고 원인까지 추적
이상 증상 접수 → 재생 시작·진행·종료 단계별 점검 → 중복 초기화 구간 특정 및 수정 → 재발 0건
영상을 빠르게 넘기면 이전 영상 소리가 겹쳐 들리는 문제가 접수됐습니다. 단순 재시작 안내로 덮지 않고, 재생이 시작되는 순간부터 끝나는 순간까지 단계를 나눠 어느 단계에서 처리가 겹치는지 직접 확인해 근본 원인을 고쳤습니다.
ISSUE 02
앱-서버 통신 두절 — 임시 우회 대신 근본 원인 추적
통신 장애 접수 → 중계 서버 주소 변경 이력 확인 → 고정 주소 할당 + 보안 통신 전환 → 재발 방지 구조 확보
중계 서버의 주소가 바뀌면서 방화벽에 막혀 통신이 끊기는 장애가 발생했습니다. 임시 재연결이 아니라 주소가 다시 바뀌어도 문제가 재발하지 않는 구조로 근본적으로 정리했습니다.
ISSUE 03
첫 화면 표시 지연 — 수치로 원인을 증명하고 개선
체감 속도 저하 접수 → 로딩 구간별 소요 시간 측정 → 불필요 리소스 정리 + 우선순위 로딩 → 표시 속도 39% 단축
화면 전환 방식을 바꾼 뒤 첫 화면이 늦게 뜬다는 피드백을 받았습니다. 감으로 판단하지 않고 구간별로 걸리는 시간을 측정해 병목 지점을 특정한 뒤 개선해 수치로 검증된 결과를 만들었습니다.
ISSUE 04
AI 낙상 감지 오작동 30% — 조건을 쪼개서 하나씩 확인
잘못된 알림 비율 30% 확인 → 형태 변화·이동 속도·유지 시간 분해 → 기준값 반복 실험 → 오작동 10% 이하로 감소
CCTV로 낙상을 감지하는 프로그램에서, 앉거나 눕는 동작을 넘어짐으로 잘못 알리는 경우가 10건 중 3건이었습니다. 결과 하나로 끝내지 않고 원인이 될 만한 조건을 나눠 하나씩 확인하며 기준을 다듬어 문제를 줄였습니다.
