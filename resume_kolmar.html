Section 02
직접 해결한 전산 운영 문제들
PROBLEM 01
방화벽 정책 변경 → 통신 두절, 재연결이 아닌 구조 재설계
통신 장애 접수 → Proxy 서버 IP 변경 이력 확인 → EC2 Elastic IP 고정 구조 재구성 → 재발 방지 구조 확보
Proxy 서버 IP가 바뀌며 방화벽에 막혀 통신이 끊기는 장애가 발생했습니다. 임시 재연결이 아니라 IP가 다시 바뀌어도 재발하지 않는 구조로 근본적으로 정리하고, SSL 인증서 적용으로 전 구간 HTTPS 전환을 함께 완료했습니다.
PROBLEM 02
간헐적 CORS 오류/데이터 이관 누락 — 로그 단위 원인 추적
특정 조건에서만 재현 → 요청/응답 헤더, 이관 로그 비교 → 특정 API 경로/조건 원인 특정 후 해결
새로고침하면 다시 되는 오류라 그냥 넘길 수도 있었지만, 원인을 두면 사용자가 늘었을 때 더 자주 터질 거라 판단해 화면별로 헤더와 로그를 하나씩 비교해 원인을 좁혀 해결했습니다.
PROBLEM 03
엑셀 산재 자산관리 — 시스템 자체 개발로 운영 리스크 제거
담당자 개인 엑셀 의존 → Java/Spring Boot/React 시스템 개발 → 실사용 데이터 2,394건 이관
담당자가 바뀔 때마다 자산 현황이 끊기는 문제를 발견하고, 데이터베이스 기반 자산관리 시스템을 직접 개발해 물품지급/라이선스 관리까지 자동화했습니다.
PROBLEM 04
헬프데스크 처리 지연 — 자동화하되 담당자 부재까지 대비
Form 접수 후 수동 확인/전달 → Teams 알림 연동 + FAQ 챗봇 이중화 → 담당자 공백에도 안내 유지

지원동기
콜마그룹은 화장품/제약 ODM 연구개발을 축으로 성장해온 조직이라, 연구와 생산 전 과정을 뒷받침하는 사내 전산 시스템의 안정성이 다른 어떤 곳보다 중요하다고 생각합니다. 연구모듈 시스템처럼 실험/생산 데이터가 오가는 환경일수록 시스템 장애나 데이터 누락이 곧바로 연구 일정에 영향을 주기 때문입니다.
홈초이스에서 실서비스 인프라를 운영하며 방화벽 정책 변경으로 반복되던 통신 장애를 구조적으로 고쳤고, 아우토크립트에서는 IT 자산관리 시스템을 직접 기획, 개발, 운영하며 사용자 요구사항을 시스템 개선으로 연결하는 일을 해왔습니다. 이 경험을 바탕으로 콜마그룹의 사내 전산 시스템 운영과 고도화에 바로 기여하고 싶습니다.
