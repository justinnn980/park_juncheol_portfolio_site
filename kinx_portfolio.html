01 / (주)홈초이스 — 통신 장애 근본 원인 추적

IP가 바뀌어도 끊기지 않는 통신 구조로 재설계

중계 서버의 IP가 바뀌자 방화벽 정책에 막혀 앱과 서버 간 요청이 전부 끊기는 장애가 발생했습니다. 증상만 우회하지 않고 네트워크 흐름을 끝까지 따라가 구조적인 원인을 찾았습니다.

  • Challenge

    중계 서버 IP가 바뀔 때마다 방화벽 정책에 걸려 앱-서버 통신이 전면 차단

  • Approach

    중계 서버에 고정 IP(EIP)를 할당해 IP 변동 자체를 제거하고, HTTP → HTTPS 전환 시 SSL 인증서를 적용해 전 구간을 암호화 통신으로 재구성

  • Result

    LG헬로비전/딜라이브 두 대형 파트너사 앱을 전환하는 동안 통신 장애 재발 없이 서비스 안정화, NCG/Multi 두 DRM 체계도 단일 구조로 통합

고정 IP + SSL 방화벽 정책 분석 AWS EC2
kinolights-crawler

→ CSV 적재, 이전 결과와 비교해 신규 진입 항목 탐지
→ 매일 자동 실행 (Cron) 후 컨테이너 종료
02 / 키노라이츠 데이터 수집 파이프라인

Python 기반 데이터 수집/처리 파이프라인을 매일 자동 운영

외부 사이트의 콘텐츠 메타데이터를 수작업으로 확인하던 방식을 Python/Selenium으로 자동화하고, Docker로 패키징해 매일 정해진 시간에 스스로 수집/비교까지 끝내도록 구성했습니다.

  • Challenge

    콘텐츠 메타데이터를 사람이 직접 주기적으로 확인/비교해야 해서 반복 작업과 누락이 발생

  • Approach

    Python/Selenium으로 수집 로직을 작성하고 Docker 이미지로 패키징, Cron으로 스케줄링해 수집부터 이전 결과 비교까지 자동 실행

  • Result

    콘텐츠 메타데이터 1,000건 이상을 평균 10분 내 수집, 신규 진입/순위 변화를 그래프로 자동 시각화

Python / Selenium Docker / Cron CSV 비교 / 시각화
