01 / LG헬로비전 → 오초이스 앱 전환

앱 재배포 없이 화면을 바꿀 수 있는 하이브리드 구조

콘텐츠 포스터가 나열되는 탐색 화면은 변경이 잦은데, 앱 내부 화면으로 관리하면 수정할 때마다 앱 심사를 거쳐야 해서 반영이 느려지는 문제가 있었습니다.

  • Challenge

    화면 하나 바꾸는 데 앱 심사 + 재배포가 필요해 운영 속도가 느림

  • Approach

    해당 화면을 React/TypeScript 웹으로 분리하고 Flutter 앱에서는 WebView로 연동, Riverpod로 최대 3대 셋톱박스 상태를 실시간 동기화

  • Result

    콘텐츠 / 배너 구성을 앱 배포 없이 즉시 반영, CDN / Lazy Loading / Skeleton UI로 초기 로딩 개선

FCP 39% ↓ LCP 10.8% ↓ React 18 / TypeScript
OTT Admin React 19 / Next.js 16 / Prisma
02 / 개인 프로젝트

기획부터 배포까지 혼자 만든 콘텐츠 관리자 페이지

실무에서 다뤄본 React 웹 화면 경험을 심화하기 위해, 서버 상태 관리 / 인증/인가 / 테스트 / CI까지 프론트엔드 실무 흐름 전체를 혼자 구현했습니다.

  • Challenge

    화면 구현을 넘어 실제 서비스 수준의 보안 / 안정성 / 품질 검증 체계가 필요

  • Approach

    JWT + RBAC를 Route Handler에서 데이터 접근 직전 재검증, 삭제는 낙관적 업데이트 후 실패 시 자동 롤백

  • Result

    단위 96개 / 브라우저 24개 / E2E 4개 테스트와 GitHub Actions CI로 회귀 없는 배포 파이프라인 구축

TanStack Query Playwright E2E GitHub Actions CI
