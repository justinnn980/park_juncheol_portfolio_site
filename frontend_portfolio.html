OTT 앱의 콘텐츠 화면을 React/TypeScript 웹으로 분리하고 WebView로 앱과 연동하는 하이브리드 구조를 직접 설계해 앱 재배포 없이 운영 요구사항을 반영했습니다. 그 과정에서 초기 로딩 성능을 FCP 39%, LCP 10.8% 개선했고, 이 경험을 심화하기 위해 React 19 / TypeScript / Next.js 16 기반 콘텐츠 관리 웹을 기획부터 배포까지 혼자 구현했습니다.

프론트엔드 역량

화면을 만드는 데서 끝내지 않고, 성능과 운영 흐름까지 책임지는 방식으로 작업합니다.

01

하이브리드 구조 설계

자주 바뀌는 화면을 React/TypeScript 웹으로 분리하고 Native 앱과 WebView로 연동해, 앱 재배포 없이 운영 요구사항을 반영하는 구조를 직접 설계했습니다.

02

로딩 성능 개선

CDN 이미지 로딩, Lazy Loading, Skeleton UI를 적용해 FCP 39%, LCP 10.8%를 개선한 실무 경험이 있습니다.

03

프론트엔드 실무 흐름 전체

서버 상태 관리, 인증/인가, 테스트, CI까지 기획부터 배포까지 혼자 구현하며 실무 흐름 전체를 경험했습니다.

01

LG헬로비전 헬로tv → 오초이스 앱 전환, 콘텐츠 화면 React 웹 전환

앱 심사 없이는 반영이 느렸던 콘텐츠 탐색 화면을 React/TypeScript 웹으로 분리 구현하고 Flutter 앱에서는 WebView로 연동하는 하이브리드 구조로 전환했습니다.

  • 기간 / 참여인원: 2025.02 ~ 2025.10 (9개월) / 풀스택 1명, 프런트엔드 2명, 디자이너 1명
  • 기술: React 18, TypeScript, Flutter, Riverpod, WebView, CDN, Lazy Loading
  • 성과: FCP 39% 단축, LCP 10.8% 개선, 앱 배포 없이 콘텐츠를 운영할 수 있는 구조 구축
  • Riverpod 기반 상태 설계로 최대 3대 셋톱박스 연결/전환 시 화면 실시간 동기화 구현

02

OTT Admin - 영화/시리즈 콘텐츠 관리자 페이지

React 웹 화면을 실무에 적용해본 경험을 심화하기 위해, 서버 상태 관리부터 인증/인가, 테스트, CI까지 프론트엔드 실무 흐름 전체를 기획부터 배포까지 혼자 구현한 개인 프로젝트입니다.

  • 기간 / 참여인원: 2026 / 개인
  • 기술: React, TypeScript, Next.js, TanStack Query, PostgreSQL, Prisma, Vitest, Playwright, GitHub Actions
  • 관리자 / 조회 전용 계정 권한 분리, 삭제 시 낙관적 업데이트 후 실패하면 자동 롤백 처리
  • JWT 세션과 역할 기반 인가(RBAC)를 Route Handler에서 데이터 접근 직전에 재검증하는 보안 설계
  • 단위 테스트 96개, 브라우저 테스트 24개, E2E 테스트 4개와 GitHub Actions CI로 품질 검증 체계 구축
