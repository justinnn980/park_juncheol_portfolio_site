실무 프로젝트 01 — OTT 앱 마이그레이션 및 웹 전환
(주)홈초이스 2024.02 ~ 2025.11
시니어 1명, 개발자 2명, 디자이너 1명 / LG헬로비전(매출 1조) / 딜라이브(매출 3,500억)
"헬로tv" 앱과 "딜라이브 모바일TV" 앱을 "오초이스" 앱으로 통합 마이그레이션. 콘텐츠 포스터가 많은 영화 선택 화면은 웹으로 분리해 앱 재배포 없이 운영 요구사항을 실시간 반영할 수 있도록 개선.
문제와 해결
  • 웹 전환 후 성능 저하 — FCP/LCP 기준 병목 분석, 스켈레톤 UI/초기 렌더링 최적화/Lazy Loading/이미지 리사이징 적용 → FCP 39%, LCP 10.8% 개선
  • 셋톱박스 페어링 상태관리 — 하나의 앱에서 최대 3개 셋톱박스 연결/종료/변경 시 콘텐츠 실시간 전환, Riverpod 기반 상태관리 구조로 안정화
  • 플레이어 중복 실행 — 쇼츠형 화면에서 플레이어 이중 초기화로 사운드 중복 출력, 원본 라이브러리 직접 수정해 Android 생명주기 레벨에서 단일 오디오 출력으로 해결
  • DRM 호환성 — 딜라이브 NCG DRM과 오초이스 Multi DRM 방식 차이를 별도 솔루션 도입 없이 플레이어 커스터마이징으로 동일 UI 제공
  • Proxy IP 변경/방화벽 차단 — EC2 Elastic IP 할당으로 고정 IP 구조 재구성해 근본 해결
  • HTTPS 전환 — SSL 인증서를 Proxy 서버에 적용해 전 구간 HTTPS 구성
Flutter 3 React 18 TypeScript Java 17 Spring Boot 2 MySQL DynamoDB MyBatis AWS Elastic Beanstalk AWS S3/EC2
